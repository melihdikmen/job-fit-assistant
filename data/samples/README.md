# Sample postings

Three postings used for the Phase 1 live run. One posting per file, plain text, UTF-8.

- File name: `<company>-<role>.txt`, lowercase, no spaces (e.g. `acme-backend-engineer.txt`).
- Paste the full posting text as it appears: title, company, location, work mode,
  requirements. Keep the original language; do not translate or summarize.
- Aim for variety: one clear fit, one where a rule should fire (on-site outside
  Ankara/Istanbul, or a junior role), one that requires strong English.

No labels are needed here. The labeled test set is `data/postings.jsonl` (Phase 2).
